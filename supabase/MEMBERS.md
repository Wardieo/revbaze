# Workspace members

Growth includes 5 invited members across all businesses; Pro includes 20. The owner does not count as a seat. Free is owner-only. Monthly prices remain $10 / $29 USD.

Settings → Members includes a business selector and lists members and pending invitations for the selected business. Choose All businesses to include every business currently owned by the account in one invitation. Businesses created later are excluded. The invitation is visible and can be revoked from any included business. Capacity is counted across every business owned by the account; the same person counts once even if they have multiple memberships. Pending invitations also reserve account capacity. Only the owner can invite, change roles, remove members, or revoke invitations. Admins edit business settings and cards/platforms; Editors edit cards/platforms; Viewers read the workspace and analytics. Billing, integrations, and ownership changes remain owner-only. Server-side RPC checks and RLS enforce permissions.

New email addresses can be invited. The same owner can resend an unfinished invitation if the bound Auth account owns no businesses, has no memberships, and has never accepted an invitation. Resends have a one-minute cooldown and retain the account-wide quota and hourly rate limit. Old invitations are revoked atomically; recipients must use the newest link. Established accounts and invitations created by another owner remain blocked. Pending invitations reserve a seat, expire after seven days, and are bound to the newly created user ID and verified email. Owners may issue at most 10 invitations per hour. Acceptance checks the current plan again. Downgrading retains memberships but pauses seats outside the plan limit; resubscribing restores eligible seats. Removed members lose their workspace access.

## Deployment

Apply migration `202610100015_workspace_members.sql` after migrations 001–014, then apply `202610100016_account_member_seats.sql` , `202610100017_all_business_invitations.sql`, `202610100018_unfinished_invitation_resend.sql`, `202610100019_invitation_completion_resend.sql`, and `202610100020_invitation_resend_countdown.sql`. Deploy `supabase functions deploy workspace-invite`. Migrations 015–020 and the invitation function were deployed to linked project `iutvtpnftgxkaeitirfa` on October 10, 2026.

Set `APP_URL` to the exact app origin (the same billing setting). Allow the app's `/?auth_callback=invite&invitation=…` redirect in Supabase Auth URL Configuration, using the appropriate origin wildcard for query parameters. Keep existing confirmation/recovery redirects permitted.

Paste `templates/invitation.html` into Supabase → Authentication → Email Templates → Invite user. Recommended subject: **You’re invited to a Revbaze workspace**. This file does not update hosted email settings automatically. Delivery uses the project's configured Supabase Auth email provider; no separate sender is used.

Owners use Settings → Members to send the invitation. Recipients follow the email, set a medium/strong password, and accept. Membership comes from the private invitation row, never a browser-supplied role or editable user metadata. Invited members enter the existing business without creating a business or purchasing their own subscription.

Tests: `node tests/members.test.mjs` covers PostgreSQL authorization and limits. `tests/members-browser.py` uses isolated mocked responses and never sends real email. An actual delivered invitation must be tested with the hosted email provider after applying its template and redirect configuration. Revoked/expired invitations may leave an unfinished Auth account; the original owner can resend until the invitation is accepted and membership is created, even if a password was saved during an earlier failed attempt. Completed accounts remain blocked. Invitation validity is checked before the password is changed, and acceptance requires a saved password. Resends use Supabase’s Magic Link email template with the invitation redirect; use the same navy branding in that hosted template if desired.
